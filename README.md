# Сайт ведущей — запуск и редактирование

Лёгкий сайт на **PHP 8.1+** без базы данных и без сторонних сервисов: всё работает на обычном российском хостинге (Timeweb, Beget, Reg.ru, Selectel, любой с PHP). Никаких CDN, Google Fonts и зарубежных админок, поэтому в РФ грузится быстро и не зависит от блокировок.

## Как устроено

| Что | Где |
|---|---|
| Страница сайта | `index.php` (собирает HTML из `data/content.json`) |
| Все тексты и ссылки | `data/content.json` (правится через админку) |
| Админка | `admin/` (адрес: `ваш-сайт.ru/admin/`) |
| Заявки с формы | пишутся в `data/leads.php`, приходят на email, видны в админке («Заявки») |
| Загруженные фото | `uploads/` |
| Резервные копии текстов | `data/backup/` (последние 30, делаются при каждом сохранении) |
| Стили и скрипты | `assets/css/style.css`, `assets/js/main.js` |

## Деплой

1. Залейте **всё содержимое папки** на хостинг в корень сайта (`public_html` или `www`).
2. Убедитесь, что PHP версии 8.1 или новее, а у папок `data/` и `uploads/` есть права на запись (обычно 755 или 775).
3. Откройте `ваш-сайт.ru/admin/`, войдите стартовым паролем (его вам передал разработчик). Система сразу попросит придумать свой пароль (минимум 10 символов).
4. Включите HTTPS (бесплатный сертификат Let's Encrypt есть у всех хостингов).
5. В админке в разделе «Общее и контакты» впишите настоящие имя, телефон, email, ссылки.

### Если хостинг на Nginx (не Apache)

Файлы `.htaccess` на Nginx не работают. Добавьте в конфиг сайта:

```nginx
location ~ ^/(data|uploads)/.*\.(php|json|log)$ { deny all; }
location ~ ^/admin/(lib|schema)\.php$ { deny all; }
location /data/ { deny all; }
error_page 404 /404.html;
```

Даже без этих правил заявки и пароль не раскроются: они лежат в `.php`-файлах, которые отдают пустую страницу или 404.

## Инструкция для клиентки (можно переслать)

1. Откройте `ваш-сайт.ru/admin/` и войдите.
2. На вкладке **«Тексты и фото»** нажмите на нужный раздел, поправьте текст.
3. Чтобы заменить фото, выберите файл в блоке «Главное фото» (JPG, PNG или WebP до 6 МБ; лучше вертикальное).
4. Чтобы добавить отзыв, этап вечера или формат, нажмите «+ Добавить». Порядок меняется стрелками ↑ ↓, лишнее удаляется кнопкой «Удалить».
5. Нажмите **«Сохранить изменения»** внизу. Всё сразу появится на сайте.
6. Вкладка **«Заявки»** показывает, кто оставил заявку через форму.

Если что-то случайно испортили, разработчик вернёт прежнюю версию из `data/backup/`.

## Что можно настроить разработчику

- **Шрифт заголовков.** Сейчас используется системный serif (Yeseva One или Playfair Display, если они установлены, иначе Georgia). Чтобы подключить свой шрифт с кириллицей, положите `.woff2` в `assets/fonts/` и добавьте в начало `style.css`:
  ```css
  @font-face { font-family: "Yeseva One"; src: url("../fonts/yeseva-one.woff2") format("woff2"); font-display: swap; }
  @font-face { font-family: "Golos Text"; src: url("../fonts/golos-text.woff2") format("woff2"); font-weight: 400 700; font-display: swap; }
  ```
- **Фото.** Сейчас стоят векторные заглушки в `assets/img/`. Клиентка заменит их через админку.
- **Цвета.** Все в `:root` в начале `assets/css/style.css`.
- **Аналитика.** Подключите Яндекс Метрику отдельным файлом `assets/js/metrika.js` (в CSP разрешены только свои скрипты, поэтому код счётчика вставляйте не в HTML, а в этот файл, и добавьте `https://mc.yandex.ru` в `script-src` и `img-src` в `index.php`).
- **Доставка заявок.** Письма идут через `mail()` хостинга. Если письма не приходят, заявки всё равно сохраняются и видны в админке.

## Безопасность (что уже сделано)

- Пароль хранится только в виде хеша (bcrypt), стартовый пароль нужно сменить при первом входе.
- Защита от перебора: 5 неверных попыток блокируют вход на 5 минут.
- Сессия: `HttpOnly`, `SameSite=Strict`, `Secure` на HTTPS; после входа ID сессии меняется.
- CSRF-токен во всех действиях админки.
- Данные при сохранении проверяются на сервере по схеме: теги вырезаются, ссылки принимаются только `http(s)`, `tel:`, `mailto:`, лишние поля игнорируются.
- Загрузки: только JPG, PNG, WebP (проверка по содержимому, не по расширению), до 6 МБ, имя файла случайное, в `uploads/` запрещено исполнение скриптов. SVG не принимаются.
- Форма заявки: honeypot-поле, ограничение «не чаще раза в 30 секунд с одного IP», защита от инъекции заголовков письма.
- Заголовки: строгая CSP (только свои скрипты и стили), `X-Frame-Options`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`. Админка закрыта от индексации.
- `target="_blank"` везде с `rel="noopener noreferrer"`. Секретов в клиентском коде нет.

**Что остаётся на стороне хостинга:** включить HTTPS и редирект с HTTP, при желании добавить заголовок HSTS, получить согласие на cookies, если подключите аналитику, и разместить страницу «Политика конфиденциальности» (в форме есть ссылка-пояснение, но сам документ нужно подготовить клиентке).

## Локальный запуск для проверки

```bash
php -S 127.0.0.1:8000
# сайт: http://127.0.0.1:8000/   админка: http://127.0.0.1:8000/admin/
```
